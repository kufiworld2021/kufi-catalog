رفع الملفات على GitHub — خطوات سريعة
=====================================

1) افتح github.com وسجّل دخول
2) اضغط الزر الأخضر "New"
   - Repository name:  catalogs
   - اختر  Public      (مهم — بدونه الصفحة ما تشتغل)
   - اضغط  Create repository

3) داخل المستودع:
   Add file  ->  Upload files
   اسحب محتويات هذا المجلد:
        index.html
        285802131/   (المجلد كامل)
   ثم اضغط  Commit changes

4) Settings  ->  Pages  (القائمة اليسرى)
   Source: Deploy from a branch
   Branch: main    و    / (root)
   اضغط Save

5) انتظر دقيقة، الرابط يصير:

   https://اسم-حسابك.github.io/catalogs/285802131/

   هذا هو الرابط اللي يروح فيه الباركود.


لإضافة منتج جديد لاحقاً
------------------------
انسخ مجلد 285802131، غيّر اسمه لرقم المنتج الجديد،
بدّل ملفات الـ PDF بداخله، وعدّل الرقم في ملف index.html.
